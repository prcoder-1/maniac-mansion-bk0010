# Замеры скорости на БК-0011М (эмулятор)

Сцены — `tools/scene.py` (БК-0011М + СМК-512 + AY): `load` состояния, затем
`prof ФАЙЛ N` и сводка `tools/prof_sum.py`. «Работа» — доля процессора вне ожидания
следующего шага в главном цикле; шаги/с зависят от темпа скриптов, поэтому сравнивать
лучше работу.
